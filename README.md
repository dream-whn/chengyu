# 成語練習室

小學成語練習網站。學生溫習成語卡、做練習；老師在後台加成語、看每個學生的練習情況。
網頁放在 GitHub Pages，資料存在你自己的 Google 試算表，全部免費。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本身 |
| `config.js` | 填上 Google 試算表後端的網址（只需改這一行） |
| `apps-script/Code.gs` | 貼到 Google Apps Script 的後端程式，內附 100 個初始成語 |

## 設定步驟（約 5 分鐘）

### 1. 建立 Google 試算表後端
1. 到 Google 雲端硬碟新增一個 **Google 試算表**，名稱隨意（例如「成語練習室資料」）。
2. 選單 **擴充功能 → Apps Script**。
3. 刪除編輯器內原有的內容，把 `apps-script/Code.gs` 全部貼上。
4. 把第 7 行的 `請改成你的密碼` 改成你自己的老師密碼。
5. 上方函式選單揀 **setup**，按 **執行**。第一次會要求授權：選你的帳戶 →「進階」→「前往（不安全）」→「允許」。
   完成後試算表會多了「成語」（已有 100 個成語）和「作答紀錄」兩個工作表。
6. 右上角 **部署 → 新增部署作業**，類型揀 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
7. 按「部署」，複製「網頁應用程式」網址（以 `/exec` 結尾）。

### 2. 填寫 config.js
把網址貼到 `config.js`：
```js
window.CHENGYU_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

### 3. 放上 GitHub Pages
1. 在 GitHub 新增一個 repository，上載 `index.html`、`config.js`（`apps-script` 資料夾和 README 可一併上載）。
2. **Settings → Pages**，Source 揀 `Deploy from a branch`，Branch 揀 `main`、資料夾 `/ (root)`，按 Save。
3. 約一分鐘後，網站會在 `https://你的帳號.github.io/repository名稱/` 出現。

## 使用方法

**學生**：打開網址 → 「練習」→ 第一次填姓名和班別學號 → 開始。每答一題都會自動上載；斷網時會先存在本機，連上後自動補上。

**老師**：按「老師後台」→ 輸入密碼。
- 學生情況：每個學生的題數、正確率、要溫習的成語；按一行看詳細紀錄；可下載 CSV。
- 成語庫：新增、修改、刪除、批量匯入（可由 Excel 複製貼上）。
- 成語難度：全班答錯率排行。
- 首三名：首頁和練習頁會顯示「成語之星」首三名（姓名、班別、已掌握成語數、正確率）。排名先比已掌握成語數，同分比正確率，再同分比作答題數。「已掌握」指答對次數不少於答錯次數，而且最近一次答對。
- 亦可以直接在 Google 試算表的「成語」工作表加行或修改，網站會自動讀取（新加的行留空 id 即可）。

## 注意事項
- **已經部署過舊版的話**：更新 Code.gs 後要按下面「修改了 Code.gs 之後」的方法部署新版本，首三名才會出現。
- 學生以「班別學號 + 姓名」識別，每次要用同一個寫法（大小寫和空格不影響）。
- 這個設計不用學生登入，方便小學生使用；但任何知道網址的人都可以用別人的名字作答。如需更嚴格，可考慮改用學校 Google 帳戶登入。
- 老師密碼只存在 Apps Script 內，學生看不到。
- **修改了 Code.gs 之後**，要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，網站才會用到新程式，網址不變。
- 例句：初始 100 個成語未有例句，所以暫時不會出「例句填空」題。在後台或試算表「例句」欄補上（例句要包含該成語）即可。
